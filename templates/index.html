QA & Verification

                        

                        

                            

                                
                                
                                URL of the QA service API. When set, BugFixer calls POST /api/run?module=<repo> after each fix instead of running tests locally.
                            

                            

                                
                                
                            

                            

                                
                                
                            

                            

                                

                                    
                                    
                                

                                P1 builds with every installed local model smallest→largest, all local models cross-check each fix, and once the CPU consensus hits the target below it's confirmed by one external slot (ramp P2→P3). If every external slot rejects, it's held for human review — never auto-committed. Accuracy over speed.
                                

                                    
                                    
                                

                            

                            

                                
                                
                                The external (cloud/GPU) confirmer is the authority that decides commit. It must Approve and reach this confidence. An Approve below it is not a rejection — its critique is fed back and the local pool rebuilds against it, same reviewer judging. Default 0.90. Floored on the reviewer's own confidence, not the blended average.
                            

                            

                                
                                
                                CPU consensus needed before an external confirmation is spent (default 0.90).
                            

                            

                                
                                
                                How far back Log Analysis looks + how often the idle snapshot refreshes (default 30).
                            

                            

                                
                                
                                Skip ensemble rungs below this size (e.g. 14 drops 7b/8b). 0 = use all installed models.
                            

                            

                                
                                
                                Hold scans/LLM work this long after boot so ollama + services come up (avoids 404s + model reload). Default 300; 0 = off.
                            

                            
                            

                                

                                    
                                    
                                

                                
Not loaded.

From a shell on this host: python3 -c "import sys; sys.path.insert(0,'/opt/bugfixer'); import auth; auth.set_password('user','newpass')"
                            

                                                        

                                
                                
                                Absolute path to the claude binary. Blank auto-detects: PATH first, then the usual install dirs. Set this when the CLI slot reports "not found" despite Claude Code being installed — the service runs as its own user with systemd's minimal PATH, so a binary that resolves in your shell can be invisible here. Find it with command -v claude.
                            

                            

                                
                                Ollama serialises requests, so a scan that starts first puts a multi-minute CPU build in the single slot and the preload queues behind it — models go resident long after the work that needed them. On by default.
                            

                            

                                
                                
                                Cap on the above, so a preload that can never succeed cannot wedge scanning. On timeout BugFixer proceeds and logs a warning. Default 3600.
                            

                            

                                
                                
                                How long a model may take to become resident (preload), separate from inference timeout. A cold load is disk → RAM plus a num_ctx-sized KV allocation, so on a CPU-only box a 14B at 32k can take well over 15 min. Default 3600. Raise this rather than lowering num_ctx.
                            

                            

                                
                                
                                Ollama prompt context size — prevents "prompt longer than context length" 400s. Default 32768; raise for very large fixes.
                            

                            

                                
                                
                                CPU threads for ollama inference. 0 = ollama default (~physical cores). Set to your allocated core count to speed big models.
                            

                            

                                
                                
                                OLLAMA_MAX_LOADED_MODELS — models kept resident at once. Set ≥ your ensemble size. Applied by running Local LLM Setup (writes ollama's systemd env).

Format: owner/repo:command
