QA & Verification

                        

                        

                            

                                
                                
                                URL of the QA service API. When set, BugFixer calls POST /api/run?module=<repo> after each fix instead of running tests locally.
                            

                            

                                
                                
                            

                            

                                
                                
                            

                            

                                

                                    
                                    
                                

                                P1 builds with every installed local model smallest→largest, all local models cross-check each fix, and once the CPU consensus hits the target below it's confirmed by one external slot (ramp P2→P3). If every external slot rejects, it's held for human review — never auto-committed. Accuracy over speed.
                                

                                    
                                    
                                

                            

                            

                                
                                
                                CPU consensus needed before an external confirmation is spent (default 0.90).
                            

                            

                                
                                
                                Override the global test command for specific repositories. Format: owner/repo:command

Chat Agent

                        

                        

                            When enabled, the chat assistant is given a compact index of your repos, open
                            issues, and processed-issue state, and may call read-only tools to drill in. It
                            can also propose running an automated fix (shown as a Confirm button). Tool-calling
                            needs a tool-capable model (llama3.1+/qwen2.5+ recommended; gemma support is limited).
                        

                        

                            

                                

                                    
                                    
                                

                            

                            

                                
                                
                                Pin chat to a specific slot — e.g. a cloud provider that's always online — so a slow local builder (P1) doesn't make chat slow. Auto uses the normal failover order.

Bug Label Priority

                                
Human-filed bugs with this label bypass the work-hours window and are processed before auto log-detected errors (bugs get the per-cycle cap first). Feature requests are unaffected (they aren't auto-processed).

                                
                                
Matches the label File-a-Bug applies (Bug). Leave blank to disable the priority tier.
